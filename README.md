# buggyroger.github.io

Persoonlijke, Nederlandstalige profielsite van Mario Mastroianni.

## Structuur

- `index.html` — semantische pagina-inhoud
- `styles.css` — responsive vormgeving
- Geen framework, buildproces of JavaScript
- Geen externe lettertypen, cookies of analytics

## Lokaal bekijken

Open `index.html` rechtstreeks in een browser, of start in deze map een eenvoudige lokale webserver:

```bash
python3 -m http.server 8000
```

Open daarna `http://localhost:8000`.
